## メソッドとは何か

### メソッドの定義と他言語との比較

まず関数とメソッドの定義です。

| 用語 | 説明 |
| --- | --- |
| メソッド | オブジェクトに結びつけられた関数 |
| 関数 | 処理をひとまとめにしたもの |

メソッドはよく関数だと説明されますが少し説明不足で、オブジェクトに紐付けられた関数になります。

Rubyは全てのデータがオブジェクトであるため必然的に関数処理は全てメソッドになります。これは他の言語における設計思想を見るとはっきりします。

```rb
# Rubyの場合
# objectにfunctionを呼び出す
object.function
# objectにfunctionをargという引数と共に呼び出す
object.function(arg)
```

```js
// JavaScriptの場合
// 関数のみで呼び出せる。データがある場合は引数に記載する
foo(arg)
```

JavaScriptなど他言語には関数単体で呼び出せる仕組みがあるのに対し、Rubyはすべてがオブジェクトのメソッドという違いがあります。

なぜこうなるかというとRubyはプリミティブ型に対応してないからです。

### プリミティブ型とは

プリミティブ型は簡単に言うと、intやstring、boolやchar、floatなどいくつかのプログラミング言語における変数の型で扱われる型です。

JavaScriptでは1や2などの数字はnumber型と呼ばれるプリミティブ型で、ただのデータとして存在します。この型が用意されていることによって数字の処理を実行することができます。

一方でRubyは1や2の数字はIntegerクラスから作られたオブジェクト（インスタンス）です。足し算引き算で使われる`+`や`-`もIntegerクラスに定義されたメソッドです。

```rb
1 + 2  # => 3
1.+(2) # => 3
# 実はRuby上では同じ挙動である。オブジェクトである1にメソッドである+を呼んでいる。
```

### メソッドはオブジェクトではないがクラスに定義されている

メソッドはデータではありませんのでオブジェクトではありません。
ただしメソッドはクラスの中に定義されています。たとえクラスの外に書いていても暗黙的にObjectクラスのメソッドになっています。

```rb
def greeting
  puts "こんにちは"
end

greeting # => "こんにちは"

# method() はMethodオブジェクトを返す
# .owner Methodオブジェクトに対してのownerを呼ぶ
method(:greeting).owner # => Object
```

またメソッドは普段はオブジェクトではないですが、method()で取り出した時だけMethodクラスのオブジェクトとして扱えます。
ちょっと複雑ですがRubyは全てがオブジェクトという思想が入り込んでいる部分ですね。

## インスタンスメソッド

さて、メソッドは基本的にクラス内で定義されているということは、ようやくクラスの中でのメソッドについて解説できるということです。

まずはインスタンスに呼び出せるメソッドとしてインスタンスメソッドがあります。

### 基本的な書き方

```rb
class Hero
  def info
    puts "勇者"
  end
end

hero1 = Hero.new # インスタンスの生成
hero1.info # => 勇者
```

### インスタンスメソッド内の `self`

インスタンスメソッド内でselfを呼ぶと、そのselfはインスタンス自身になります。

```rb
class Hero
  def info
    self
  end
end

hero1 = Hero.new
hero1.info # => #<Hero:0x...> hero1自身が返ってくる
```

これはセッターメソッドの呼び出しで使われることが多いですが細かい話になるため一旦割愛します。

### インスタンス変数との関係

インスタンス変数はインスタンスが作られた時に代入されるインスタンスごとの変数です。
`@変数名`で記載されているのがインスタンス変数になります。

```rb
class Hero
  # インスタンスを作る際にnewメソッドより渡された引数をインスタンス変数に渡す
  # これによってメソッド内でインスタンス変数を使った処理を行うことが可能になります。
  def initialize(hp, atk)
    @hp = hp
    @atk = atk
  end

  def info
    puts "勇者のHP: #{@hp}, 攻撃力: #{@atk}"
  end
end

hero1 = Hero.new(30, 5)
hero1.info # => 勇者のHP: 30, 攻撃力: 5
hero2 = Hero.new(20, 10)
hero2.info # => 勇者のHP: 20, 攻撃力: 10
```

## クラスメソッド

### クラス自体もオブジェクト

RubyにおいてはクラスもClassクラスのインスタンスです。

```rb
# HeroはClassクラスのインスタンスから生まれたオブジェクト
p Hero.is_a?(Object) # => true
p Hero.class # => Class
```

オブジェクトということはメソッドを持てるということです。

ただしこの場合はインスタンスメソッドではなくクラスが持つためクラスメソッドとなります。

### 定義と呼び出し

```rb
class Hero
  # ここでのselfはクラスを意味している
  def self.info
    puts "私は勇者だ"
  end
end

# インスタンスを建てなくてもメソッドを呼び出せる
Hero.info # => 私は勇者だ
```

### クラスメソッド内の `self`

```rb
class Hero
  def self.info
    # クラスメソッド内ならselfはクラス自身に変わる
    self
  end
end

# そのためこの場合はHeroクラス自身が返ってくる
Hero.info # => Hero
```

### どんな時に使うか

クラスメソッドはインスタンスに依存しないメソッドであるため集計や検索に向いています。

```rb
class Hero
  @@all = [] # クラス変数。全てのインスタンスで共有されます

  attr_reader :name, :lv

  def initialize(name,lv)
    @name = name
    @lv = lv
    @@all << self # インスタンスを作る度に@@allの配列にインスタンス自身の参照を追加
  end

  # 例えば指定lv以上の勇者を検索するメソッドを作る
  def self.lv_over(lv)
    @@all.select{ |hero| hero.lv >= lv }
  end
end

Hero.new("アリス", 20)
Hero.new("ボブ", 30)
Hero.new("カイル", 40)

Hero.lv_over(25) # => ボブとカイルのインスタンスが返り値として返される。
```

あくまでRubyとして書くならこのようになりますが実務ではほぼ書くことはありません。

ただしRailsで`User.where(...)`などと書けるのは**ActiveRecord**にて定義されたクラスメソッドによって活用できるようになります。

## まとめ：本質的な違い

- インスタンスメソッドは**個別のインスタンス**で使うことを目的としたメソッド
- クラスメソッドは**クラス全体に関わる処理やインスタンスに依存しない処理**を行うメソッド
- selfはインスタンスメソッドでは呼び出したインスタンス、クラスメソッドではクラス自身と振る舞いを変える

基本的にRubyを書く場合はインスタンスメソッドが基本です。ですがメソッドを定義する前にどちらで定義するか判断することが大事です。
