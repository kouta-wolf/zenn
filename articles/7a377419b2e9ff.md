## はじめに

**Obsidianでのタスク管理はプロパティの入力が煩雑になりがちです**。これなら既存のSaaS（TodoistやNotion等）でいいよねと感じる方も多いでしょう。

でもObsidianの自由度とローカル管理は捨てがたいので、TemplaterとModal formsを組み合わせて手軽さと詳細設定の良いとこどりが出来るようにしました。

メリット：

- デイリーノートと紐付けられる（BasesかDataview）
- 型の決まったフォームを自由に設定できる。プロパティの初期値も自動入力。
- コマンド呼び出しやボタンですぐにタスク登録画面を呼び出せる。

※ 筆者も試行錯誤してるためもっと良い方法があればご指摘いただけると幸いです。

当記事ではTemplaterとModal Formsをつかったタスク入力システムの構築を紹介します。

## 注意点

本記事では1ノート1タスクを想定しています。
表示方法はBasesやDataview、Full Calendarなど自分の環境に合わせてプロパティ値や設定を変更してください。
デスクトップ版でのみ動作確認を行っています。

## 必要なもの

導入方法の詳細は割愛しますので各自プラグインを有効にしてください

必須:

- Templater: Modal formsから値を受け取るために使用
- Modal forms: 入力画面を作成するために使用

推奨: 記事内で使用例として使っています

- Bases, Dataview: タスク一覧の表示用
- Meta Bind, Button: フォーム呼び出しボタンの作成

## 全体的なワークフロー

仕組みの全体像はこの通りです。

1. Meta Bindで作られたボタンを押す
2. Modal formsの入力画面に内容を入力
3. Templaterがその内容を受け取り、特定のフォルダにタスクノートを自動生成
4. 一覧表示プラグインに反映される

## 手順1: Modal Formsでフォームを作成する

### 1. Formの新規作成

コマンドパレットでModal forms: New formを起動し、名前（Form unique name）を決めます。

- Form unique name:  `task-form`（後のスクリプトで使用します）
- Form title: 新規タスク作成 (フォーム画面に表示される名前)

### 2. Fieldsの設定

タスクに必要な項目を追加します。この通りでなくても良いですがNameは値を参照するキーになるので分かりやすい名前を入力してください。

| Name (key) | Label | Type | 備考 |
| --- | --- | --- | --- |
| `taskName` | タスク名 | Text | タスク自体のタイトル名 |
| `folder` | フォルダ | Select | workかprivateか |
| `startDate` | 開始日 | Date | |
| `dueDate` | 締切日 | Date | |
| `priority` | 優先度 | Select | high, mid, lowの3つ |
| `description` | 概要 | Text | |

Selectタイプの項目（folder, priority）は、設定画面下の Options から選択肢を追加してください。
下のPreviewボタンで実際の挙動を確認しながら進めるのがおすすめです。

## 手順2: Templaterのスクリプトを作成する

TemplaterがModal Formsから値を受け取り、ノートの生成とプロパティの流し込みを行うJavaScriptを書きます。
Templater用のフォルダにタスク用の新規ノートを作成し、その中に貼り付けてください。

:::message
Templaterでプロパティ（YAML）を作ってしまうためテンプレートノートのプロパティは削除してください。
:::

### 1. スクリプト例

```javascript:TaskTemplate.md
<%*
// Modal formsの呼び出し
const modalForm = app.plugins.plugins.modalforms.api;
const result = await modalForm.openForm('task-form'); //手順1で決めた名前

// キャンセル時は処理を終了
if (!result || result.status === "cancelled") {
    return;
}

// データの抽出（result.data['Name'] で取得
// || の後ろにデフォルト値を設定できます
const genID = tp.date.now("YYYYMMDDHHmm");
const genDate = tp.date.now("YYYY-MM-DD");
const f_title = result.data['taskName'] || "新規タスク";
const f_folder = result.data['folder'] || "07_tasks/private";
const f_start = result.data['startDate'] || tp.date.now("YYYY-MM-DD");
const f_due   = result.data['dueDate'] || tp.date.now("YYYY-MM-DD", 1, f_start, "YYYY-MM-DD");
const f_prio  = result.data['priority'] || "low";
const f_desc  = result.data['description'] || "";

// OSで使用禁止されている文字を除去しファイル名変更
const safeTitle = f_title.replace(/[\\/:*?"<>|]/g, "");
await tp.file.rename(safeTitle);

// 指定したフォルダへ移動
await tp.file.move(`${f_folder}/${safeTitle}`);

// ノート内容の組み立て
const noteContent = `---
ID: ${genID}
date: ${genDate}
tags:
  - ${f_folder}
  - task
priority: ${f_prio}
start_date: ${f_start}
due_date: ${f_due}
done: false
description: ${f_desc}
---

## 概要
- ${f_desc}

## 進捗
`;

// 書き出し
tR += noteContent;
%>
```

### 2. コードのカスタマイズについて

- 各種プロパティは筆者が使っているものなのでその時に応じて書き換えてください。
- `result.data['...']`: ここに入れる名前は、手順1で作ったフォームのNameと一致させる必要があります。

:::message
`tp.file.move`: フォルダが存在しないとエラーになるため、あらかじめ移動先のフォルダを作成しておいてください。
:::

## 手順3:ホットキーやボタンで呼び出す

作成したファイルをワンアクションで起動できるようにします。

### 1. Templaterの設定でコマンドにする

作成したテンプレートファイルはコマンドとして登録します

1. 設定の Templater > Template Hotkeys セクションを探す。
2. 手順2で作成したノートを登録する。

これでコマンドパレットから Templater: Create (ノート名) として呼び出せるようになります。

### 2. ボタンを設置する（任意）

MetaBindやButton等のプラグインを使うとより直感的に起動できます。

Meta Bindを使う場合はコマンドパレットのMeta Bind: open button builderで作成画面を呼び出せます。

MetaBindコード例：

```meta-bind-button
label: 新規タスク
icon: ""
style: default
class: ""
cssStyle: ""
backgroundImage: ""
tooltip: ""
id: ""
hidden: false
actions:
  - type: command
    command: templater-obsidian:create-999_templates/Task.md

```
